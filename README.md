# Jarvis AI

Персональный русскоязычный голосовой ассистент для Windows 10/11. Проект развивается отдельно в аккаунте Andrik717.

## Возможности
- Русское распознавание речи через faster-whisper.
- Локальный диалоговый ИИ через Ollama (по умолчанию модель Qwen 2.5 3B).
- История разговора в рамках текущего запуска.
- Естественная русская нейросетевая озвучка через Microsoft Edge TTS.
- Настройка модели, адреса Ollama и мужского/женского голоса из окна приложения.
- API-ключи не требуются: Ollama работает локально на компьютере.

## Первый запуск ИИ
1. Установи Ollama для Windows: https://ollama.com/download
2. Открой командную строку и выполни:
   ```powershell
   ollama pull qwen2.5:3b
   ```
3. Дождись окончания загрузки модели. Ollama должна быть запущена.
4. Обнови Jarvis AI и запусти `run.bat`.

По умолчанию приложение обращается к `http://localhost:11434` и модели `qwen2.5:3b`. Если используешь другую модель, поменяй её в кнопке «НАСТРОЙКИ ИИ».

## Голос
По умолчанию используется нейросетевой голос `ru-RU-SvetlanaNeural`. В настройках можно выбрать `ru-RU-DmitryNeural`. Для генерации голоса требуется интернет. Windows SAPI оставлен как резервный вариант в коде, но не является основным голосом.

## Установка и обновление
Требуется Python 3.11+ (рекомендуется 3.12).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
run.bat
```

Настройки хранятся локально в `%APPDATA%\JarvisAI\settings.json`. Секреты не следует коммитить в Git.

## Архитектура
- `jarvis/config.py` — локальные настройки.
- `jarvis/asr.py` — распознавание речи.
- `jarvis/brain.py` — локальный ИИ и контекст диалога.
- `jarvis/tts.py` — нейросетевая озвучка и резервный SAPI.
- `jarvis/app.py` — интерфейс и голосовой цикл.
