# Jarvis AI

Персональный русскоязычный голосовой ассистент для Windows 10/11.

## Возможности
- Русское распознавание речи через faster-whisper.
- Локальный диалоговый ИИ через Ollama (по умолчанию Qwen 2.5 3B).
- История последних реплик между запусками программы.
- Долговременная память фактов по команде «Запомни, что…».
- Естественная русская нейросетевая озвучка Microsoft Edge TTS.
- Мужской голос по умолчанию: `ru-RU-DmitryNeural`.
- Голосовые команды Windows: браузер, блокнот, калькулятор, проводник и основные папки.
- Открытие популярных сайтов и поиск в интернете голосом.
- API-ключи для локального ИИ не требуются.

## Первый запуск
1. Установи Ollama: https://ollama.com/download
2. Выполни `ollama pull qwen2.5:3b`.
3. Убедись, что Ollama запущена.
4. Запусти `run.bat`.

По умолчанию используется `http://localhost:11434` и модель `qwen2.5:3b`.

## Голосовые команды
Примеры:
- «Джарвис, открой браузер».
- «Открой YouTube», «Открой Steam», «Открой Telegram».
- «Открой блокнот», «Открой калькулятор», «Открой проводник».
- «Открой загрузки», «Открой документы», «Открой рабочий стол».
- «Найди в интернете погоду в Хельсинки».

Команды запускают только заранее разрешённые приложения и сайты. Произвольные команды оболочки не выполняются.

## Установка и обновление
Требуется Python 3.11+ (рекомендуется 3.12).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
run.bat
```

Для обновления запусти `update.bat`, затем `run.bat`.

Настройки и память хранятся локально в `%APPDATA%\JarvisAI\`: `settings.json`, `conversation.json` и `memory.json`. Эти файлы не публикуются в репозитории.

## Структура
- `jarvis/config.py` — настройки.
- `jarvis/asr.py` и `jarvis/audio.py` — распознавание и микрофон.
- `jarvis/brain.py` — локальный ИИ, история и память.
- `jarvis/tts.py` — нейросетевая озвучка Дмитрием.
- `jarvis/pc_control.py` — безопасные команды Windows.
- `jarvis/app.py` — интерфейс и голосовой цикл.
