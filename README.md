# Jarvis AI

Персональный русскоязычный голосовой ассистент для Windows 10/11. Проект развивается отдельно в аккаунте Andrik717.

## Цели
- Быстрый локальный захват речи и распознавание русского языка.
- Настраиваемые модели и OpenAI-compatible API для диалога.
- Локальные команды выполняются без обращения к LLM.
- Естественная озвучка с несколькими backend и явной диагностикой fallback.
- Настраиваемая панель управления и безопасные разрешения для действий.

## Статус
Начальная инженерная основа. Это не готовый релиз: функции будут добавляться и проверяться поэтапно.

## Запуск (Windows)
Требуется Python 3.11+ (рекомендуется 3.12).

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.bat
```

Настройки хранятся локально в `%APPDATA%\JarvisAI\settings.json`. Секреты не следует коммитить в Git.

## Архитектура
- `jarvis/config.py` — настройки и безопасное хранение параметров.
- `jarvis/asr.py` — faster-whisper, русский язык, быстрый режим распознавания.
- `jarvis/tts.py` — озвучка через Windows SAPI и опциональный HTTP TTS backend.
- `jarvis/app.py` — приложение и интерфейс (следующий этап).
